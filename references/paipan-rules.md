# 排盘规则速查（与 `scripts/ziwei_pan.py` 同口径）

本文件是排盘算法规格的**唯一权威口径说明**。脚本按此实现，判盘时引用本书断语前，
应先确认这里的三处流派分歧用了哪一档。

> **凡本文与 `chapters/` 章节目录下的原书提炼不一致，以本文为准**——本文写的是
> 脚本实际行为；章节文件保留原书表述以便研究。

---

## 一、三处流派分歧（脚本提供开关）

### 1. 大限起宫 —— `--daxian`

| 档位 | 起宫 | 依据 |
|---|---|---|
| `quanshu`（**默认**） | 阳男阴女：命前一宫（**父母宫**）顺行；阴男阳女：命后一宫（**兄弟宫**）逆行 | 《全书》卷三明言「阳男阴女从命前一宫起顺行（是父母宫），阴男阳女从命后一宫起逆行（是兄弟宫）」 |
| `common` | 自**命宫**起，方向同上 | 坊间多数排盘软体（含 iztro 等）采用 |

**为何默认 quanshu**：本技能的根基是《全书》。但对外部工具排出的盘时，注意对方
多用 `common`，差一宫。

> 注意：两种口径下「起岁 = 局数」是一致的，差别只在**首宫**。

### 2. 闰月 —— `--leap-policy`

| 档位 | 规则 | 依据 |
|---|---|---|
| `next-month`（**默认**） | 闰月生者一律作**下一月**算 | 《全书》「凡有闰月具要依此为例」 |
| `split15` | 闰月前十五日作本月，后十五日作下一月 | 通行折中法；iztro 的 `fixLeap=true` 即此档 |

**影响范围**：只影响「依生月」安的星（左辅、右弼、天刑、天姚）与**安身命用的生月**。
**依生日起的紫微一律用真实农历日**，两档相同。

**闰月判定**：以**日**为粒度——某月首日至次月首日之间（前闭后开）不含任何中气**日**
即为闰月。不可用精确时刻比较（朔与中气同日而时刻先后不同时，闰月会错位）。

### 3. 晚子时 —— `--late-zishi`

| 档位 | 规则 |
|---|---|
| `next-day`（**默认**） | 23:00–23:59 生：农历「日」按次日计，时支仍作子 |
| `same-day` | 保留当日的农历日 |

**影响范围**：只影响**依生日**起的紫微（因农历日进一日）。安身命用的是生**时**，
时支两档都是子，故命宫不受影响。

### 4. 年柱分界 —— `--year-divide`

| 档位 | 规则 |
|---|---|
| `exact`（**默认**） | 以立春**精确时刻**分界（与八字 skill 同口径） |
| `day` | 立春**当日**即算新年 |

**为何需要这个开关**：外部工具（如 iztro）在年柱上按日切换、在月柱上按时刻切换，
内部并不一致。要与外部工具逐盘对齐，须取 `day`。

> 立春精确时刻由太阳视黄经 315° 定气算出，不写死日期。

## 二、排盘步骤（顺序不可乱）

### 第 0 步：真太阳时（在定时辰之前，不可跳过）

**钟表时 ≠ 真太阳时。** 中国全境用北京时间（东经 120° 基准），西部各地实际经度差很大：

```
总校正(分) = (出生地东经 − 120) × 4 + 均时差EoT(出生日)
真太阳时   = 钟表时 + 总校正
```

- **经度时差**：每度 4 分钟。成都 ~104.1°E → −64 分；昆明 ~102.7°E → −69 分；
  乌鲁木齐 ~87.6°E → −130 分；北京 ~116.4°E → −14 分。
- **均时差 EoT**：地球轨道偏心与黄赤交角所致，全年在 −14 ~ +16 分之间摆动
  （脚本用 NOAA 简化式，精度约 ±0.5 分）。约在 2 月中旬最负（−14 分）、
  11 月初最正（+16 分）。

**这一步会直接改变时辰**，从而改变命宫、身宫、五行局、紫微与全部安星。
在西部长大的人身上，跨时辰是常见情况，不是边缘案例。

```bash
# 成都（约东经 104.07°）
# 钟表时 13:30（未时）→ 真太阳时 12:20（午时）—— 跨了一个时辰
python3 scripts/ziwei_pan.py --lunar 1994-06-20 --hour 13:30 --sex 男 --longitude 104.066
```

脚本会把自己的计算过程写进 `## 警告`，包括校正明细、是否跨时辰、是否距边界 15 分内。
**判读时应把这段原样告知用户，以便复核。** 加 `--no-true-solar` 可关闭校正。

> 原书《论人生时要审的确》：「必须罗经以定真确时候，**若差讹则命不准矣**。」
> 古人用日晷/罗经取的正是真太阳时，本步即恢复此口径。

### 第 1 步：农历换算
由公历得农历年、月、日、是否闰月（定气定朔）。闰月判定见上。

### 第 2 步：年干支
以立春分界定生年干支 → 得到**生年干**（定四化、禄存、魁钺等）与
**生年支**（定天马、火铃、命主所依等）。

### 第 3 步：安身命
```
月支宫 = 寅 + (生月 - 1)          # 寅起正月顺数；闰月按 --leap-policy 修正生月
命宫   = 月支宫 - 生时步数          # 逆数
身宫   = 月支宫 + 生时步数          # 顺数
```
子=0、丑=1 …… 亥=11。闰月生者在下一月内起。

### 第 4 步：五行局
```
寅宫天干 = 五虎遁(生年干)     # 甲己丙寅、乙庚戊寅、丙辛庚寅、丁壬壬寅、戊癸甲寅
命宫天干 = 寅宫天干顺推 (命宫位次)
局数     = 纳音五行 -> {水2, 木3, 金4, 土5, 火6}
```
局数 = 大限起始岁数。

### 第 5 步：起紫微、天府

**紫微**（「局数除日数，商数宫前走」）：
```python
offset = 0
while (农历日 + offset) % 局数 != 0:
    offset += 1
商 = (农历日 + offset) // 局数
本位 = 寅 起 1 顺数至商
紫微 = 本位 + offset   if offset 为偶    # 进
       本位 - offset   if offset 为奇    # 退
```

**天府**：与紫微以**寅申为轴**镜像。
```
天府位 = (12 - 紫微位) mod 12      # 位次以寅=0 计
```
紫微在寅 ↔ 天府在寅（同宫），在申 ↔ 申（同宫），其余两两成对。

### 第 6 步：十四主星

**北斗支**（自紫微**逆**行）：
```
紫微(0) → 天机(-1) → 太阳(-3) → 武曲(-4) → 天同(-5) → 廉贞(-8)
```
（口诀：紫微天机逆行旁，隔一阳武天同当，又隔二位廉贞地，空三复见紫微郎）

**南斗支**（自天府**顺**行）：
```
天府(0) → 太阴(+1) → 贪狼(+2) → 巨门(+3) → 天相(+4) → 天梁(+5) → 七杀(+6) → 破军(+10)
```

（口诀：天府太阴与贪狼，巨门天相及天梁，七杀空三破军位）

## 三、运限

### 大限
起岁 = 局数，每宫十年，方向与起宫见「一、1」。

### 小限
**不论阴阳，男顺女逆**，一年一宫。起宫依**生年支三合**：

| 生年支 | 起宫 |
|---|---|
| 寅午戌 | 辰 |
| 申子辰 | 戌 |
| 巳酉丑 | 未 |
| 亥卯未 | 丑 |

### 童限（局数前的过渡）
一命二财三疾厄四妻五福六官禄，顺行，十五岁回命宫。

### 南北斗应期

| 类型 | 吉星来源 | 大限应期 | 小限应期 |
|---|---|---|---|
| 阳男、阴女 | 南斗为福 | 下五年 | 下半年 |
| 阴男、阳女 | 北斗为福 | 上五年 | 上半年 |

### 太岁
流年干支按 `(年 - 4) mod 60`，1984 = 甲子。
流禄/流羊/流陀：按流年干用禄存口诀，前羊后陀。

## 五、历法精度边界

- **朔**用 Meeus 定朔简式，精度约 1–2 分钟。
- 若某朔落在子夜前后数分钟内，农历换算可能与官方历书**差一日**
  （1900–1920 年间偶见，抽样约 0.3%）。脚本对此会输出警告，请用权威农历工具复核。
- 定气（节气）精度约十余分钟，用于立春/月柱分界足够；
  但**生日恰好落在交节时刻前后数分钟内**时，年柱归属可能有流派差异，
  脚本会提示「节气交界」。
- 覆盖范围：**1900–2100**。
