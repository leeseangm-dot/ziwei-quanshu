# 第十四章：谈星要论与命格高下

## 核心要旨
本章是卷三的**方法论总纲**：给出「看命次第」的固定流程（几步看什么），建立「格星数高下」的九等分级体系，并明确**男女命判读顺序的根本差异**。前面十二章是零件，本章是装配说明书。

---

## 一、谈星要论 —— 看命次第

**总原则**：
> 看身安命禄马不落空亡天空截空最紧，旬空次之。

**次第**（原文）：
1. **第一看命宫**吉凶庙旺化吉化忌生克。
2. **次看身主**吉凶生克。
3. **三看迁移财帛官禄三方**星辰刑冲克破。
4. **四看福德宫**权禄劫空庙陷（以福德宫对财帛宫也）。

**核心概念——八座**：
> 身命迁移财官福德六宫名曰八座，俱在成照聚吉化吉，富贵高寿。
> 六宫俱陷，聚凶化忌，孤寡夭寿。

**要义**：这六个宫位（身、命、迁移、财帛、官禄、福德）合称「八座」，是判断**整体格局层次**的第一层筛选。全部吉 → 富贵高寿；全部凶 → 孤寡夭寿。

**补充规则**：
- 又看**父母妻子三宫**，俱有劫空杀忌 → 僧道之命，否则孤独贫穷。
- **若命宫无正曜**者，财官二宫有吉星拱照 → 富贵全美，或偏房庶母所生；三方有恶星冲照 → 或二姓可延生，离祖可保成家。

### 命格等级（谈星要论版）
| 等级 | 条件 |
|---|---|
| **上上之命** | 命宫有正曜吉星，庙旺化吉，三方又有吉星会合 |
| **上次之命** | 无正曜吉星，三方有吉 |
| **中格** | 命宫星辰无吉无凶，或吉凶相伴；三方亦有中等星辰 |
| **破格** | 命宫星辰庙旺，三方有恶星守照破格 |
| **中等之命（次）** | 命星陷背，加羊陀化忌，却得十干禄元来相守化吉 |
| **下格之命** | 命无吉星，反有凶杀化忌无禄落陷 |
| **下格贫贱** | 安命星躔陷地，又加凶杀化忌，三方又会羊陀火铃空劫 —— 二姓延生，奴仆之命，否则夭折六畜之命 |
| **中等（先小后大）** | 三方有吉星，亦可为中等，先小后大，不能久远，终为成败夭折论 |

**关键机制——「得十干禄元来相守化吉」**：即使命星落陷化忌，只要**生年的禄元**（该年干的化禄星）来守，仍可拉回中等之命。这是原书给出的**唯一一个「陷地翻身」的杠杆**。

## 二、论人命入格

**入格 vs 不入格的四种组合**：
| 条件 | 结论 |
|---|---|
| 入格，庙旺聚吉，科权禄守 | **上上之命** |
| 不入庙加吉化科权禄 | 上次之命 |
| 不入庙不加吉 | 平常命 |
| 入庙不加吉 | 平等 |
| 居陷地又加杀化忌 | **下格之命，不以入格而论** |

**核心规则**：
> 又入格不化吉而化凶，只以本命吉凶多寡而断之。

**要义**：「入格」不等于吉。若该格成立但星曜化凶，则不按格论，改按吉凶数量断——**格局名只是条件成立，不是结论**。

---

## 三、论格星数高下 —— 九等分级

**判据是「星」与「数」两维**：
- **星**：星曜本身的层次（上格/中格/下格）。
- **数**：紫府与数的相合程度（阴阳相伴、数相生）——阴阳纯驳为中格；三方四正皆吉星为上格；吉凶相伴为中格；凶星恶杀为下格。

**九等表**：
| 等 | 星 | 数 | 结论 |
|---|---|---|---|
| 第一 | 上格 | 上格 | **位至极品之贵** |
| 第二 | 上格 | 中格 | 位至三公 |
| 第三 | 上格 | 下格 | 位至六卿 |
| 第四 | 中格 | 上格 | 位至监司 |
| 第五 | 中格 | 中格 | 位至县令 |
| 第六 | 中格 | 下格 | 异路前程贵显 |
| 第七 | 下格 | 上格 | **衣禄丰足，富比陶朱**，子孙蕃盛，寿享遐龄（星虽凶而命入格合局故也），否则虚名虚利 |
| 第八 | 下格 | 中格 | 衣食无亏 |
| 第九 | 下格 | 下格 | 辛苦奔波，贫穷夭折 |

**要义**：
1. **星与数可以互相补偿**。「星得下格而数得上格」仍可富比陶朱——因为「命入格合局」。
2. 第 1–3 等「皆为上格上寿之人」；第 4–6 等「皆得中等享福主人也」。
3. 第九等才是真正的凶：「辛苦奔波，贫穷夭折」。
4. 原书结尾：「上中下三等，依理而断，则上可以知祖宗之源，而下可以知子孙之盛衰也。」

## 四、论男女命同异

**男命次第**：
1. 先看**身命**。
2. 次看**财帛、官禄、迁移**——俱要庙旺为吉，落陷聚凶为凶。
3. 三看**福德**——权禄劫空庙陷吉忌。
4. 又看**田宅、奴仆、疾厄**宫吉凶。
5. 又看**父母、妻子三宫**——俱有劫空杀忌则僧道之命，否则贫穷孤独。

**女命次第**：
1. 先看**身命**吉凶——如贪狼七杀擎羊则不美。
2. 次看**福德宫**吉凶——**若七杀单居福德必为娼婢**。
3. 三看**夫君（夫妻宫）**。
4. 四看**子媳、财帛、田宅**。

**男女权重对照**（核心差异）：
| 项目 | 男命 | 女命 |
|---|---|---|
| 强宫 | 财帛、官禄、福德、迁移、田宅 | **子媳、夫君、福德**为正强；田宅、财帛为次强 |
| 陷宫 | 子女、奴仆、兄弟、父母 | **官禄、迁移、七杀**为陷 |

**关键判语**：
> 女因夫贵，女命贵格反为无用，以子媳夫君福德为正强。田宅财帛为次强。宫禄迁移七杀为陷。

**要义**：
- 男命的「官禄、迁移」是强宫，女命却是「陷宫」——**同一宫位，男女吉凶相反**。
- 女命「贵格反为无用」，因为女因夫贵，自身贵格不直接转化为福。
- 男命若父母妻子三宫俱有劫空杀忌则僧道之命；女命则看福德（七杀单居必为娼婢）。
- 但女命也有底线条款：「虽是艰辛贫困亦不为下溅夭折论」——**诸吉庙旺则佳**，即女命见吉星庙旺，即便贫苦也不作下贱夭折断。

## 五、论小儿命

**小儿看法的特殊性**：小儿**大小二限未行**，故不看运限，只看本命星辰庙旺与关杀。

**判据**：
| 情况 | 结论 |
|---|---|
| 命中星辰庙旺，大小二限未行 | 断其灾少，易养，父母无克 |
| 命坐恶杀及缠陷弱之地，大小二限未行 | 断其灾多，难养，刑克父母 |

**十二神煞在小儿期的表现**：
> 小儿博士力士上短下长，青龙将军腮小头圆。大耗鼻仰唇缩，死符病符声高性雄。官府奏书逢恶曜落地无声，白虎太岁遇七杀幼弱遭伤。

**要义**：须「分生克制化之垣，更看时禄衰败之地，后观关杀方知寿夭穷通」——三步：生克制化 → 时禄衰败 → 关杀。

**金锁铁蛇关**（小儿关煞）：
> 当从戌上起子年，顺数行年月逆推，日又顺数时逆转，小儿寿夭可先知。
> 此法从戌上起年顺行至本生年，年上起月逆数至本生月，月上起日，月上起时，逆至本生时遇丑未宫病有救，辰戌宫死。

## 七、论人生时安命吉凶 与 论人生时要审的确

**安命吉凶**：
> 凡男女生在**寅午戌申子辰六阳时**，安命在此六宫者吉。生在**巳酉丑亥卯未六阴时**，安命在此六宫者吉。反此则少遂。

**要义**：阳时生人安命阳宫为吉，阴时生人安命阴宫为吉——**阴阳同类相得**。

**审时的严谨性**：
> 如人生子亥二时最难定，准要仔细推详，如子时有十刻，上午刻属昨夜亥时，下午刻属今日子时，如天气阴雨之际，必须罗经以定真确时候，若差讹则命不准矣。

**要义**：子、亥二时最易混，且古人已意识到**跨时辰边界**的问题（子时前段实属亥时）。「若差讹则命不准」——生时是整盘的基础。

## 推演实例：用「格星数高下」给一张盘定级

情境：某人命宫在午，紫微庙旺守命，三方四正会左右昌曲，生年乙（乙年化禄天机、化权天梁、化科紫微、化忌太阴）。

1. **判「星」**：紫微庙于午，三方皆吉星 → **星得上格**。
2. **判「数」**：紫微为南北斗中天帝主，三方四正皆吉星无恶杀 → **数得上格**。
3. **查九等表**：星上数上 = **第一等，位至极品之贵**。
4. **验入格**：查第八章贵局——「紫府朝垣」（命坐寅申加吉星）、「辅弼拱主」（紫微守命，二星来拱）、「君臣庆会」（紫微左右同守命）。本例命在午，若得府相朝拱则「紫府朝垣」成立。**入格 + 庙旺聚吉 + 科权禄守 → 上上之命**。
5. **校正项**：
   - **四化**：乙年化科正在紫微——科星加于帝座，主文贵显达。但乙年**化忌在太阴**，须查太阴落宫。若太阴陷于卯辰巳，则「日月最嫌反背」之忌加重。
   - **八座检查**：身、命、迁移、财帛、官禄、福德六宫是否俱吉。若福德宫见破军则「劳心费力不安」，即便官禄贵显，也只能「得中等享福主人」。
   - **性别修正**：若为女命，官禄、迁移转为**陷宫**——紫微庙旺的优势须改由福德、夫妻、子女三宫承接。此时「紫微女命守身宫，天府尊星同到宫」才是主判据。
6. **结论**：男命定为上上之命，主贵；女命则须以福德、夫妻宫重新评估，官禄贵格「反为无用」。

**要点**：定级流程是「评星 → 评数 → 查九等 → 验入格 → 四化校正 → 八座检查 → 性别修正」。前四步定层次，后三步定实际成败。

## 反模式
- **跳过「看命次第」直接断宫**：原书给出明确顺序（命宫→身主→迁移财官→福德），顺序本身携带权重信息。
- **忘记「八座」六宫筛选**：身命迁移财官福德是整体层次的第一道筛子，缺一看会误判高下。
- **把「入格」直接当吉断**：原书明言「入格不化吉而化凶，只以本命吉凶多寡而断之」。
- **男女命套用同一权重**：官禄、迁移在男命是强宫、女命是陷宫；男命父母妻子三宫关乎僧道，女命则看福德。混用必然出错。
- **给小儿看运限**：小儿大小二限未行，只论本命与关杀。
- **生时不确定仍强行推盘**：原书对子亥二时的告诫是「若差讹则命不准矣」。
- **忽略「得十干禄元相守」这条翻身路径**：落陷化忌之命未必是下格，禄元来守可回升中等。

## 关键要点
1. 看命次第：命宫 → 身主 → 迁移财帛官禄 → 福德；父母妻子三宫作补充筛。
2. 「八座」= 身命迁移财官福德六宫，是整体格局层次的第一道筛选。
3. 命格九等由「星」与「数」两维交叉决定，**星与数可互相补偿**（星下数上仍富比陶朱）。
4. 「入格」只代表条件成立，星曜化凶时改按吉凶多寡断。
5. 男女命权重根本不同：男主财官福迁田，女主夫妻子福；官禄迁移在女命为陷。
6. 小儿不看运限，只看本命星辰与关杀；不知生时可依「定小儿生时诀」反推。
7. 阳时生人宜安命阳宫，阴时生人宜安命阴宫。
