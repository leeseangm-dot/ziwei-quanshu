# 第一章：罗序与太微赋 —— 源流与总纲

## 核心要旨
《紫微斗数全书》的定位是「以天合之人，人合之天」：把星辰变化翻译成人命休咎。太微赋是全书总纲，讲的是**判盘的基本次序与权重**，不是星性清单。

## 源流
- **托名作者**：陈抟（字图南，自号扶摇子，宋初道士，赐号「希夷先生」）。书中尊称「希夷公」。
- **序作者**：罗洪先，明嘉靖庚戌（1550）春三月，赐进士及第、吉水人。
- **传承叙事（重要）**：书非陈抟直传。罗洪先辞官访道至华山谒陈抟祠，遇一道者「年方二十有六」，自称陈抟**第十八代**孙，道号「了然」，出示此书。罗以自己生辰试排，「果毫发不爽」。
  - **要点**：序作者自己写明了这一层，即此书是明代人从一位自称十八代孙的年轻道士手中所得。读此书应知其文本为明代整理的托名之作。

## 太微赋：判盘总纲
### 星曜分布的基本框架
- **十二垣 / 三十六位**：星分十二宫垣，数定三十六位。「入庙为奇，失度为虚。」
- **身命为本**：以身命宫为福德之本，以根源为穷通之资。
- **必明生克**：须明生克之要，详得垣失度之分。

### 帝星与列宿的统属关系
- 「帝星动则列宿奔驰」——紫微一动，全盘星曜随之位移。
- 「贪守空而财源不聚」——贪狼落空亡，财不聚。
- 「各司其职，不可参差。」

## 判盘次序（太微赋隐含的流程）
1. **先看身命**——身命为祸福之本。
2. **次看星曜得垣失度**——庙旺落陷决定星力。
3. **再观生克制化**——星与星、星与宫的生克。
4. **后断限元**——大限、小限、流年层层叠加。
5. **终看制化与救助**——有无吉星解救。

## 反模式
- **只看单星断吉凶**：太微赋反复强调「再观生克之机」「细察制化之理」，单星不足以定论。
- **忽略身命而先论限**：赋中次序以身命为本，「命好身好限好到老荣昌；命衰身衰限衰终身乞丐」。
- **以庙旺为绝对吉**：庙旺星若被冲破（禄逢冲破），反「吉处藏凶」。
- **执死数不改**：太微赋末句「学至此诚玄微矣」，是提醒学者此学至玄至微，需活看。

## 推演实例：如何读一条太微赋判词
以「禄逢冲破，吉处藏凶」为例，完整推演：

1. **识别主星**：命宫或三方有化禄（如甲年廉贞化禄）。
2. **找冲破之物**：化禄是否被地空、地劫、擎羊、陀罗、化忌同宫或对照？
3. **判生克**：若化禄所属五行被宫位五行所克（如廉贞火化禄落亥子水宫），本身已受制。
4. **看有无救**：是否有禄存、天梁、紫微同宫化解？
5. **综合断**：
   - 有救 → 中局，财来财去但不断根。
   - 无救 → 「吉处藏凶」，表面有财实则破败。
6. **叠加限元**：若大限再逢此宫，是爆发点。

**要点**：这条判词不是说「化禄不好」，而是说化禄被破坏后，凶性比原本无禄更隐蔽——因为当事人会以为自己在走好运。

## 关键要点
1. 此书是明代托名陈抟的整理本，罗序自陈来源，读者应知其为「明代总结」而非宋人亲传。
2. 太微赋是判盘总纲：身命为本 → 得垣失度 → 生克制化 → 限元叠加 → 制化救助。
3. 「入庙为奇，失度为虚」——庙旺落陷是星力的基本刻度。
4. 判词的读法是**条件式的**：每条都是「若X则Y」，须逐项验证条件是否成立。
5. 帝星（紫微）在盘中有统属全局的地位，「帝星动则列宿奔驰」。
