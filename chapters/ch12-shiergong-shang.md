# 第十二章：论十二宫（上）——命宫至疾厄

## 核心要旨
卷二的「一命宫」到「十二父母」是全书**最实用的断语库**：每一宫都按「星曜 → 该星在此宫的断语」逐条列出，格式统一为**通用断语 + 男命吉凶诀 + 女命吉凶诀 + 入限吉凶诀 + 宫位年干配合**。本章覆盖前六宫：命宫、兄弟、妻妾、子女、财帛、疾厄。

---

## 一、命宫

**命宫是总纲**——一切判读从此出发。原文先总述紫微，再逐星展开。

### 紫微（示例条目，展示该宫的条目结构）

> 紫微守命最为良，二杀逢之寿不长，羊陀火铃来相会，只好空门礼梵王。
> 紫微辰戌遇破军，富而不贵有虚名，若逢贪狼在卯酉，为臣失义不相应。

> 紫微女命守身宫，天府尊星同到宫，更得吉星同主照，金冠封赠福滔滔。

### 四化入命断诀
| 化 | 男命诀 | 女命诀 |
|---|---|---|
| **化禄** | 「十干化禄最为荣，男命逢之福自申」 | 吉凑作命妇，内外威严，杀凑平常 |
| **化权** | 「权星最喜吉星扶，事业轩昂胆气粗」 | 「化权吉曜喜相逢……富贵双全人性硬，夺夫权柄」 |
| **化科** | 「科星文宿最为奇，包藏锦绣美文章」 | 「化科女命是良星，四德兼全性格清」 |
| **化忌** | 「诸星化忌不宜逢，更会凶星愈肆凶」 | 「女命化忌本非奇，更遇凶星是祸基」 |

**化忌的关键细则**：
> 如遇紫府昌曲同吉利，权禄与忌同宫又兼羊火铃空作事进退，横发横破，始终不得久远……一生奔波劳碌或带疾贫夭。
> 然**天同在戌化忌，丁生人遇吉；巨门在辰化忌辛生人返佳**。
> 若**太阳在寅卯辰巳午化忌，太阴在酉戌亥子化忌为福论**。若日月陷地化忌，主大凶。
> 如廉贞在亥化忌是也，火入泉乡，又逢水命人化忌也不为害。

**要义**：化忌不是绝对凶——当化忌落在该星**庙旺**之地时反为福论（太阳在庙旺宫化忌、太阴在庙旺宫化忌皆然），只有落在陷地才主大凶。

## 四、子女宫

**判读法则**（原书明列）：
1. **先看本宫星宿主有几子**。若加羊陀火铃空劫杀忌，主生子女有刑克。
2. **次看对宫有冲刑否**。
3. 如本宫无星曜，**专看对宫**有何星宿主有几子。
4. 善星贵星守子女宫 → 生子昌盛贵显；恶星同刑杀守 → 不是刑克，主生强横破荡之子。
5. **再看三方四正**：得**南斗星多主生男，北斗星多主生女**。
6. **太阳落在阳宫主先生男，太阴落在阴宫主先生女**。
7. 专看刑杀守本宫无制化相生，**必然绝祀**。
8. **日生最怕太阴临，夜生最怕太阳照**——此星若在儿女宫方恐无儿。

## 反模式
- **只看本宫不看命宫（疾厄宫）**：原书明定疾厄须先看命宫落陷加煞情况，再论本宫。
- **子女宫忽略对宫与三方**：本宫无主星时必看对宫；男女之别有「南斗多男、北斗多女」与「太阳在阳宫先生男」两套规则。
- **妻妾宫不看「迟娶免刑」**：武曲、天府、羊陀入庙、七杀皆以迟婚为解，直接断克是漏读救法。
- **把化忌一律当凶**：太阳、太阴在庙旺宫化忌为福论；天同在戌化忌、巨门在辰化忌在特定年干下返佳。
- **财帛宫只看星曜不看「闹中/白手」的区别**：前者是取财方式，后者是发迹路径，混同会导致断语失准。
- **忽略女命断语的独立性**：每宫皆有专列的女命吉凶诀，女命不可直接套用男命断语。

## 关键要点
1. 卷二每宫的固定结构：通用断语 → 男命诀 → 女命诀 → 入限诀 → 年干配合。
2. 命宫是唯一「逐星全列」的宫位，其他宫位按星给出简明断语。
3. 疾厄宫须命宫与疾厄宫合看；子女宫须本宫、对宫、三方四正合看。
4. 婚姻宫的核心救法是「迟娶免刑」；财帛宫的核心区分是「闹中取财」与「白手生财」。
5. 女命断语不可与男命互换，每宫皆单独给出。
6. 四化在不同庙陷下的吉凶可能反转，不可一概而论。
