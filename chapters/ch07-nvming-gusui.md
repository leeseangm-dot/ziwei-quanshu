# 第七章：女命骨髓赋 —— 女命专论

## 核心要旨
女命判断与男命**不同盘、不同次序、不同强弱宫**。本篇给出女命的专用判词与优先级。

## 女命的判盘次序（与男命的关键差异）
依卷三「论男女命同异」：
1. **先看身命吉凶** —— 如贪狼、七杀、擎羊则不美。
2. **次看福德宫吉凶** —— 若七杀单居福德，必为娼婢。
3. **三看夫君**（夫妻宫）。
4. **四看子媳、财帛、田宅。**
5. 若桃花刑杀要败绝空亡为凶；若诸吉庙旺则佳。

**女命强宫与男命不同**：
- **正强**：子媳、夫君、福德
- **次强**：田宅、财帛
- **陷**：官禄、迁移、七杀

对比男命以「财帛、官禄、福德、迁移、田宅」为强宫——**女命官禄宫反而为陷**，这是本书明确的性别差异断法。

## 女命骨髓赋原文

> 府相之星女命躔，必当子贵与夫贤。
> 廉贞清白能相守，更有天同理亦然。
> 端正紫微太阳星，早遇贤夫性可凭。
> 太阳寅到午，遇吉终是福。
> 左辅天魁为福寿，右弼天相福来临。
> 禄存厚重多衣食，府相朝垣命必荣。
> 紫府巳亥相互辅，左右扶持福必生。
> 巨门天机为破荡。天梁月曜女命贫。
> 擎羊火星为下贱。文昌文曲福不全。
> 武曲之宿为寡宿。破军一曜性难明。
> 贪狼内狠多淫佚。七杀沉吟福不荣。
> 十干化禄最荣昌，女命逢之大吉昌。
> 更得禄存相凑合，旺夫益子受恩光。
> 火铃羊陀及巨门，天空地劫又相临。
> 贪狼七杀廉贞宿，武曲加临克害侵。
> 三方四正嫌逢杀，更在夫宫祸患深。
> 若是本宫无正曜，必主生离克害真。

## 女命吉星分组

**吉**：
- 天府、天相 → 子贵夫贤（首要吉星）
- 廉贞 → 清白能相守
- 天同 → 与廉贞同理，清白相守
- 紫微、太阳 → 端正，早遇贤夫
- 太阳在寅到午 → 遇吉终是福
- 左辅、天魁 → 福寿
- 右弼、天相 → 福来临
- 禄存 → 厚重多衣食
- 府相朝垣 → 命必荣
- 紫府在巳亥相互辅 + 左右扶持 → 福必生
- **十干化禄 → 最荣昌，大吉昌**
- 化禄 + 禄存相凑 → 旺夫益子受恩光

**凶**：
- 巨门、天机 → 为破荡
- 天梁、月曜（太阴落陷） → 女命贫
- 擎羊、火星 → 为下贱
- 文昌、文曲 → 福不全
- **武曲 → 为寡宿**
- 破军 → 一曜性难明
- 贪狼 → 内狠多淫佚
- 七杀 → 沉吟福不荣
- 火铃羊陀 + 巨门 → 凶
- 天空、地劫相临 → 凶
- 贪狼、七杀、廉贞、武曲加临 → 克害侵
- **三方四正逢杀，更在夫宫 → 祸患深**
- **本宫无正曜 → 必主生离克害**

## 女命格局（定富贵贫贱中的相关条目）
- 「十二宫诸星得地合格诀」中：未宫立命 → 女人值此全福寿；寅宫 → 男子为官女受封；卯宫 → 女人享福受褒封。
- 女命不宜见：羊刃、三合羊刃冲、贪巨月昌组合。

## 反模式
- **用男命的强弱宫判女命**：女命官禄宫为陷、夫妻宫为正强，与男命相反。用男命标准判女命是根本性错误。
- **忽略「本宫无正曜」的硬规则**：「若是本宫无正曜，必主生离克害真」——女命命宫无主星是明确的凶断。
- **不看夫宫只论命宫**：赋中明说「更在夫宫祸患深」，女命夫妻宫优先级极高。
- **把「武曲为寡宿」当绝对**：武曲入庙仍主权贵，是「陷地值杀」才孤单。需先定庙陷。
- **忽略化禄的加分**：「十干化禄最荣昌」是女命最强的吉星组合，且须「更得禄存相凑合」方为全美。

## 推演实例：女命盘的核心判断流程
情境：某女命，命宫天机在子，夫妻宫巨门，福德宫七杀，三方见擎羊。

1. **第一步——身命吉凶**：天机在子为入庙（依卷一分论「子午宫入庙」）。天机入庙女命「性刚机巧，有权柄持家，助夫益子」——基础为吉。
2. **第二步——福德宫**：福德为七杀。依卷三「若七杀单居福德必为娼婢」——**这是硬凶断**，格局大幅下降。需看七杀是否入庙、有无吉星同宫化解。
3. **第三步——夫君（夫妻宫）**：巨门在夫妻宫。依巨门十二宫断语「在夫妻主于隔角，生离死别，纵夫妻有对不免污名失节」。若巨门在辰戌为陷地，更凶。
4. **第四步——三方四正**：见擎羊。赋云「擎羊火星为下贱」「三方四正嫌逢杀，更在夫宫祸患深」。擎羊若落夫妻宫三方，叠加巨门 → 凶上加凶。
5. **综合判断**：
   - 天机入庙：吉（基础）
   - 七杀单居福德：凶（关键降级项）
   - 巨门在夫妻 + 羊：凶（婚姻）
   - **结论**：虽命宫入庙，但福德与夫妻两处皆凶，为下局。宜看有无化禄、禄存、天梁化解。
6. **化解方向**：寻天梁（能制破军之恶、化暴戾为祥和）、化禄与禄存（「十干化禄最荣昌，更得禄存相凑合，旺夫益子受恩光」）。

**要点**：女命断法的权力在**福德与夫妻**，不在命宫。命宫再好，福德夫妻有硬伤仍属凶局。

## 关键要点
1. 女命与男命**判盘次序不同**：女命次看福德，三看夫君；男命次看财帛官禄迁移。
2. 女命的强宫是子媳、夫君、福德；官禄、迁移为陷——与男命相反。
3. 「武曲为寡宿」「贪狼入庙必为娼」「七杀单居福德必为娼婢」是三条最重的女命凶断。
4. 「十干化禄」是女命最强吉星，配禄存为全美。
5. 「本宫无正曜，必主生离克害」是硬规则。
6. 女命见煞三方，尤其在夫宫，祸患最深。
