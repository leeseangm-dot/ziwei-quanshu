# 第十章：安星诀总汇

## 核心要旨
本章汇总全书所有星曜的**安放口诀**，按「依何而定」分成五类：依**生时**、依**生月**、依**生年干**、依**生年支**、依**生日/命宫/流年**。记住分类就记住了口诀——因为安星法的依据决定了该星的**性质**：依时者应事于时辰，依年干者应事于化气与禄权。

---

## 一、依本生时定的星

| 星 | 口诀 | 说明 |
|---|---|---|
| **文昌** | 子时戌上起文昌，逆到生时是贵乡 | 从戌起子时，**逆行**到生时 |
| **文曲** | 文曲数从辰上起，顺到生时是本乡 | 从辰起子时，**顺行**到生时 |
| **天空、地劫** | 亥上起子顺安劫，逆向便是天空乡 | 劫**顺**、空**逆**，同起亥宫 |
| **台辅** | 由午宫起子顺数至本生时安之 | 午起子，顺行 |
| **封诰** | 由寅起宫子顺数至本生时安之 | 寅起子，顺行 |

**要点**：昌曲一对一逆一顺，空劫一对一顺一逆——这是紫微斗数最常见的**镜像对称**设计，不可记混。

## 三、依本生年干定的星

### 安南北斗诸星诀（十四主星起法）
> 紫微天机逆行旁，隔一阳武天同当，又隔二位廉贞地，空三复见紫微郎，
> 天府太阴与贪狼，巨门天相及天梁，七杀空三破军位，八星顺数细推详。

**拆解**（以紫微所在为起点）：
- **北斗支**（逆行）：紫微 → 天机（隔一宫）→ 隔一宫为太阳 → 武曲 → 天同 → 隔二宫为廉贞 → 空三宫复见紫微。
- **南斗支**（顺行）：天府 → 太阴 → 贪狼 → 巨门 → 天相 → 天梁 → 七杀（空三宫）→ 破军。

### 安禄权科忌四星变化诀（**最要紧的四化表**）
> 甲廉破武阳为伴，乙机梁紫月交侵，丙同机昌廉贞位，丁月同机巨门寻，
> 戊贪月弼机为主，己武贪梁曲最平，庚日武阴同为首，辛巨阳曲昌至临，
> 壬梁紫府武宿是，癸破巨阴贪狼停。

| 乙 | 天机 | 天梁 | 紫微 | 太阴 |
| 丙 | 天同 | 天机 | 文昌 | 廉贞 |
| 丁 | 太阴 | 天同 | 天机 | 巨门 |
| 戊 | 贪狼 | 太阴 | 右弼 | 天机 |
| 己 | 武曲 | 贪狼 | 天梁 | 文曲 |
| 庚 | 太阳 | 武曲 | 太阴 | 天同 |
| 辛 | 巨门 | 太阳 | 文曲 | 文昌 |

**要义**：四化是**唯一随年干变化**的星曜系统，也是判断命局「谁被激活、谁被破坏」的核心。同一张星盘，生年干不同，四化完全不同，吉凶可以彻底反转。

## 四、依本生年支定的星

| 星 | 口诀 |
|---|---|
| **天马** | 寅午戌人马居申，申子辰人马居寅，巳酉丑人马居亥，亥卯未人马居巳 |
| **火星、铃星** | 寅午戌人丑卯方，申子辰人寅戌扬，巳酉丑人卯戌位，亥卯未人酉戌房 |
| **天哭天虚** | 天哭天虚起午宫，午宫起子两分踪，哭逆巳兮虚顺未，数到生年便居中 |
| **龙池凤阁** | 龙池子顺辰，凤阁子戌逆 |
| **红鸾天喜** | 卯上起子逆数之，数到当生太岁支，坐守此宫红鸾位，对宫天喜不差移 |

**天马七变**：天马虽一条口诀，但因年支不同落于四生位（寅申巳亥），故有「寅午戌马在申」等七种组合，加上流年天马、月马、日马等，共称七变。

**红鸾附加断语**：
> 年少婚姻喜事奇，老人必主丧其妻，三十年前为吉曜，五十年后不相宜。

### 依命宫（相对位置）
| 星 | 口诀 |
|---|---|
| **天伤、天使** | 命前六位是天伤，命后六位天使当（伤安奴仆宫，使安疾厄宫） |

## 推演实例：为一个盘安满星曜

情境：承第九章实例——辛丑年、二月、巳时生，命宫在戌，木三局。
1. **十四主星**：先按木三局定紫微（设初一则紫微在辰），再依「安南北斗诸星诀」逆布天机、太阳、武曲、天同、廉贞；自天府（紫微在辰 → 天府在子）顺布太阴、贪狼、巨门、天相、天梁、七杀、破军。
2. **依生时**：巳时 → 文昌自戌逆至巳 = **文昌在未**；文曲自辰顺至巳 = **文曲在巳**。劫空：自亥顺安劫至巳、自亥逆安空至巳 → **劫空同在巳**（巳时劫空同宫）
3. **依生月**：二月 → 左辅自辰顺至二月 = **左辅在巳**；右弼自戌逆至二月 = **右弼在酉**。
4. **依年干（辛）**：天魁在**午**、天钺在**寅**；禄存在**酉**；擎羊在**戌**（禄前）、陀罗在**申**（禄后）；四化——辛巨阳曲昌 → **巨门化禄、太阳化权、文曲化科、文昌化忌**。
5. **依年支（丑）**：天马 —— 巳酉丑人马居亥 → **天马在亥**；火铃 —— 巳酉丑人卯戌位 → **火星在卯、铃星在戌**；天哭天虚自午起子，丑年到未 → 哭从天**逆**至丑年、虚从申**顺**至丑年；龙池自辰起子顺至丑 = **龙池在巳**、凤阁自戌起子逆至丑 = **凤阁在酉**。
6. **依命宫**：命宫戌 → 天伤在命前六位 = 辰；天使在命后六位 = 午。
7. **依生日**：取生日起初一日顺左辅宫（巳）数至生日 → 三台位置；起初一逆右弼宫（酉）数至生日 → 八座位置。
8. **长生十二神**：木局命 → 亥起长生，男命顺行。
9. **十二神煞**：丑年阳男（假设）→ 自禄存（酉）顺推博士，依次安力士、青龙…… 全盘铺满。

**关键校验**：文昌在未而**文昌化忌**（辛年），文曲在巳而**文曲化科**——同宫昌曲一对一忌一科，此为典型「昌曲分途」，主聪明才智但科名有阻。这一步就是「安星」转向「论命」的接口。

## 反模式
- **把昌曲、空劫的方向记反**：昌逆曲顺、劫顺空逆。四个方向两两对称，是最高频的排盘错误来源。
- **羊陀不随禄存**：羊陀永远夹禄存（前羊后陀）。若把羊陀单独由年干直接查表，极易错位。
- **忽视四化的年干专属**：四化不是固定配置，必须查生年干。用错年干的四化表会导致整盘吉凶反转。
- **红鸾天喜不问年龄**：原书明言「三十年前为吉曜，五十年后不相宜」——同一星曜，年龄不同吉凶相反。
- **长生十二神不分男女**：男顺女逆，方向相反。
- **十二神煞起法不分阴阳男女**：阳男阴女顺推，阴男阳女逆行，起于禄存。

## 关键要点
1. 安星口诀按依据分五类：生时、生月、生年干、生年支、生日/命宫/流年。
2. 昌曲（逆/顺）、空劫（顺/逆）、辅弼（顺/逆）、魁钺、羊陀（前/后）均为成对镜像设计。
3. 四化是唯一随年干变动、且能翻转吉凶的星曜系统，十六字口诀须背熟。
4. 天伤天使恒居奴仆、疾厄二宫，永远是「夹地」的来源。
5. 十四主星的排布只有一条口诀（安南北斗诸星诀），但拆成北斗逆行、南斗顺行两支。
6. 十二神煞起于禄存，方向由「阳男阴女顺、阴男阳女逆」决定。

## 关联
- **第九章**：命宫、五行局、紫微是本章全部口诀的坐标原点。
- **第十一章**：星曜安好后，用庙旺落陷表与南北斗五行分类赋予其力量等级。
- **第五章**：辅佐星、四化、煞星的**性质**解释在此补齐了**位置**。
- **第十五章**：大限、小限、童限与斗君、流年诸星的安法，是运限判断的基础。
