# 第八章：格局论 —— 十等论与富贵贫贱局

## 核心要旨
本篇是全书**格局的判定手册**：先用「定富贵贫贱十等论」给人分类，再用「十二宫诸星得地/失陷」判断命宫所在宫位的合格与否，最后用「定富局/贵局/贫贱局/杂局」匹配具体格局名。

---

## 一、定富贵贫贱十等论

| 论 | 条件 | 结论 |
|---|---|---|
| **福寿论** | 南人：天同天梁坐命庙旺；北人：紫微武曲破军贪狼坐命旺宫 | 福寿双全 |
| **聪明论** | 文昌文曲天相天府武曲破军三台八座左辅右弼三合拱照 | 极聪明 |
| **威勇论** | 武曲文昌擎羊七杀坐命宫得权禄，三方又得紫微天府左右拱照 | 威勇 |
| **文职论** | 文昌文曲左辅右弼天魁天钺坐命旺宫，又得三方四正科权禄拱 | 为文官 |
| **武职论** | 武曲七杀坐命庙旺宫，又得三台八座加化权禄及天魁天钺并拱 | 为武职 |
| **刑名论** | 擎羊陀罗火铃星武曲破军带杀上吉凑合，三方四正无凶不陷 | 主刑名 |
| **富贵论** | 紫微天府天相禄权科太阴太阳文昌文曲左辅右弼天魁天钺守照拱冲 | 大富贵 |
| **贫贱论** | 擎羊陀罗廉贞七杀武曲破军天空地劫忌星三方四正守照拱冲，诸凶并犯陷地 | 主贫贱 |

## 反模式
- **只看星曜组合不看生年干**：得地合格诀每一条都绑定年干（「庚辛乙癸生人美」）。同一宫位组合，生年不同结论相反。
- **把「得地合格诀」当绝对吉断**：寅宫「巨日足丰隆」仍需「申巳庚人皆为吉」——生年不符则不成立。
- **忽略「纵然化吉」的限定**：失陷破格诀多处写「纵然化吉更为美，任他富贵不清宁」——化吉只能改善，不能翻转。
- **富贵局与贫贱局对冲时不分主次**：如「禄马佩印」与「马落空亡」都涉及天马，区别在同宫星曜。须逐条核对条件。
- **忘记杂局是运限格局**：把「枯木逢春」当命局来断是类别错误。

## 推演实例：用十等论与格局给一个人分类
情境：某人命宫在卯，武曲守命，三方见文昌、左辅右弼，擎羊在酉，生年辛。

1. **查得地合格诀**：「卯宫机巨武曲逢，辛乙生人福气隆，男子为当縻廪禄，女人享福受褒封」——武曲守卯且生年辛，条件成立，为合格。
2. **查富贵论**：「武曲守卯福丰盈」——成立。
3. **查贵局**：「武曲守垣——武守命卯宫是也，余不是」——武曲在卯正是武曲守垣格，成立。
4. **查十等论**：
   - 「威勇论」需武曲文昌擎羊七杀坐命 + 权禄 + 紫府左右拱 → 有武曲、文昌、擎羊，看是否有七杀与权禄。部分成立。
   - 「聪明论」需昌曲府相武破 + 台座辅弼三合 → 有武曲、文昌、辅弼，接近成立。
5. **检查破格**：擎羊在酉。卯的三合为亥卯未，酉不在其中。故擎羊不直接破卯命宫。但若擎羊在卯同宫 → 失陷破格诀「卯上太阴擎羊逢」不成立（因命宫是武曲非太阴）。
6. **综合结论**：
   - 合格 + 贵局 + 生年相配 → 中上格，「武曲守垣」主财官。
   - 若三方另有七杀与擎羊 → 转「威勇论」或「刑名论」。
   - 若见空劫 → 「君子在野」需核对。
7. **校正**：查「武曲巳亥逢，六甲帅边庭」——武曲在巳亥配六甲生人主武职边疆。本例在卯，不适用，转而依卯宫条。

**要点**：流程是「宫位合格诀 → 富贵/失陷论 → 具体格局名 → 十等论归类 → 破格检查」。多个体系交叉验证，取一致结论。

## 关键要点
1. 十等论是**类型识别**（福寿、聪明、威勇、文职、武职、刑名、富贵、贫贱、疾殀、僧道）。
2. 得地合格诀的核心是**宫位 + 星曜 + 生年干**三者共同决定，缺一不可。
3. 富贵局与贫贱局的判词都以「条件式」给出，须逐条核对，不可凭局名判断。
4. 杂局描述的是运限形态，是动态格局，与静态富贵局分属不同层次。
5. 大量格局名在此定型：紫府朝垣、日月并明、月朗天门、明珠出海、财荫夹印、君臣庆会、坐贵向贵等。

## 关联
- **第六章**：骨髓赋提供大量同类判词，与本章互补。
- **第十章**：庙旺落陷是判断「得地/失陷」的基础。
- **第十四章**：卷三论格星数高下把格局细分为上中下九等。
- **第十六章**：诸星同垣各司所宜给出每颗主星的细部格局断语。
