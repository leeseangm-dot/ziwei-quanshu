# 第九章：安身命例与起例总纲

## 核心要旨
本章是**排盘的起点**：如何从生年月日时定出命宫与身宫，如何定十二宫次序，如何由年干起五行局、由生日定紫微所在，以及命主、身主、十二宫强弱与「落闲」的判定。**安命一错，全盘皆错**——原书开篇即警告「若错了则失之毫厘，差之千里矣」。

---

## 一、安身命例（定命宫身宫）

**总诀**：人命俱从**寅上起正月**，顺数至本生月止，又自生月起子时**逆**至本生时安**命**，**顺**至本生时安**身**。

**推演步骤**：
1. 寅宫定作正月，顺行数到出生月份，落定「月支宫」。
2. 从该宫起子时，**逆时针**数到出生时辰 → 安**命宫**。
3. 从该宫起子时，**顺时针**数到出生时辰 → 安**身宫**。

**举例**：正月生子时 → 寅宫安身命（月宫即寅，子时不动）。丑时 → 逆转丑安命，顺去卯安身。寅时 → 逆转子安命，顺至辰安身。

**闰月规则**：闰月生者，**在下一月内起安身命**（如闰正月作二月算）。

**安十二宫例**：男女俱从命宫**逆转**（切忌顺去）。
> 一命宫、二兄弟、三妻妾、四子女、五财帛、六疾厄、七迁移、八奴仆、九官禄、十田宅、十一福德、十二父母

**要义**：十二宫永远逆布，且顺序固定。兄弟宫必在命宫逆时针下一宫，父母宫必在命宫顺时针下一宫。

## 二、起五行局（决定紫微定位）

**第一步——由年干起寅宫天干**：
| 生年干 | 寅宫起 |
|---|---|
| 甲、己 | 丙寅 |
| 乙、庚 | 戊寅 |
| 丙、辛 | 庚寅 |
| 丁、壬 | 壬寅 |
| 戊、癸 | 甲寅 |

**第二步——由命宫干支查纳音，定五行局**：
口诀「甲己之年丙为首，乙庚之岁戊为头」（即上表），得出命宫所属干支后，查六十花甲子纳音歌，取其五行即为**局数**。

**六十花甲子纳音歌（节选，须熟读）**：
> 甲子乙丑海中金，丙寅丁卯炉中火，戊辰己巳大林木，庚午辛未路旁土，壬申癸酉剑峰金，
> 甲戌乙亥山头火，丙子丁丑涧下水，戊寅己卯城头土，庚辰辛巳白蜡金，壬午癸未杨柳木，
> 甲申乙酉泉中水，丙戌丁亥屋上土，戊子己丑霹雳火，庚寅辛卯松柏木，壬辰癸巳长流水,
> 甲午乙未沙中金，丙申丁酉山下火，戊戌己亥平地木，庚子辛丑壁上土，壬寅癸卯金箔金，
> 甲辰乙巳覆灯火，丙午丁未天河水，戊申己酉大驿土，庚戌辛亥钗钏金，壬子癸丑桑柘木，
> 甲寅乙卯大溪水，丙辰丁巳沙中土，戊午己未天上火，庚申辛酉石榴木，壬戌癸亥大海水。

**五行局名称与序数**：水二局、木三局、金四局、土五局、火六局。**局数 = 起紫微的「岁数」起点**，也是大限起始年龄。

**举例**（原书示例）：甲生人安命在寅 → 甲己之年丙为首 → 丙寅丁卯炉中火 → **火局**（火六局）。

## 三、安紫微（由生日与局数定位）

核心原理：局数 = 紫微起始宫位所对应的「日数周期」。举火六局之例：「如是正月初一生者是火局，**酉宫起初一日**，就从酉宫起紫微」。以下为各局定紫微口诀：

| 局 | 口诀 |
|---|---|
| **水二局** | 坎水宫中二岁行，初一起丑初二寅，顺行一宫安二日，阴阳虽殊行则同 |
| **木三局** | 生逢木宫三岁起，初一起龙初二牛，逆进二宫安二日，顺回四步一辰字，初二同宫牛头起，逆退二步二辰寻 |
| **金四局** | 紫微金宫四岁花，初一寻猪初二龙，顺进三步逆退一，先阴后阳是其基，惟有初二辰上起，退三进四逆寻迹 |
| **土五局** | 戌土五龙居其中，初一午上二亥宫，逆行二宫安一日，惟有九日不能均，十居辰上初居寅，二十九日五上寻，二宫一日顺三次，退二三次又逆回，惟有六日无正位，逢四对宫去追寻 |
| **火六局** | 离火宫中六岁奇，初二骑马初四龙，进三退二各一日，逆回三步是生时，先阳后阴逆退二，另有进一各期端，退二安一退二日，顺进五宫方是基 |

**安天府**：`天府惟寅申二宫紫府同宫，余宫俱各填协作对如紫居丑则府居卯矣。`
——紫微与天府以**寅申一线为对称轴**镜像分布。紫微在丑，天府必在卯；紫微在寅，天府亦在寅（同宫）。

## 四、定十二宫强弱与落闲

### 定十二宫弱强
| 性别 | 强宫 | 弱宫 |
|---|---|---|
| **男命** | 财帛、官禄、福德、迁移、田宅 | 子女、奴仆、兄弟、父母 |
| **女命** | 夫君（夫妻）、子息（子女）、财帛、田宅、福德 | 余宫皆弱 |

**要义**：男女强宫不同，是全书反复出现的判读原则。男重「财官福迁田」，女重「夫妻子财田福」。

### 定十二宫星辰落闲
紫微在**子辰亥**为闲宫；贪狼在**寅辰**；天相在**辰戌**；七杀在**辰亥**；天梁在**巳酉**；天机在**巳**；破军在**巳申**；武曲在**申**。
**要义**：落入闲宫的星曜，力量大幅折损，吉不见吉、凶也不见凶——判断时应视为「失位」。

## 五、命主与身主

**安命主**（由命宫地支定）：
| 命宫地支 | 命主星 |
|---|---|
| 子 | 贪狼 |
| 丑、亥 | 巨门 |
| 寅、戌 | 禄存 |
| 卯、酉 | 文曲 |
| 辰、申 | 廉贞 |
| 巳、未 | 武曲 |
| 午 | 破军 |

补充：`左辅随丑至午，右弼随亥至午`（即辅弼二星亦可作命主，按同表推定）。

**安身主**（由生年支定）：
| 生年支 | 身主星 |
|---|---|
| 子、午 | 火星（铃星） |
| 丑、未 | 天相 |
| 寅、申 | 天梁 |
| 卯、酉 | 天同 |
| 辰、戌 | 文昌 |
| 巳、亥 | 天机 |

**判读差异**：命主代表**先天本质与根源**，身主代表**后天际遇与外貌行藏**。二者生克关系是「看命次第」的第二步（见第十四章）。

## 六、论星辰生克制化

> 星曜全明生克制化之机，次看落于何宫。如廉贞属火在寅宫，乃木乡能生廉贞之火，若武曲金星与廉贞同度，则武曲为财而无用也。

**受制格局**：
> 金入火乡、火入水乡、水入土乡、土入木乡 —— 俱为受制。

**应用**：先看星曜本身，再看宫支的五行对星曜的生克，最后看同宫星的五行互制。三层叠加，才定该星是否得力。

---

## 推演实例：排一个盘的起点

情境：辛丑年、二月、巳时生，欲定命宫、五行局与紫微。
1. **定月宫**：寅为正月顺行 → 二月在**卯**。
2. **定命身**：从卯起子时逆数到巳时：子卯、丑寅、寅丑、卯子、辰亥、**巳戌** → **命宫在戌**；顺数同日时 → 子卯、丑辰、寅巳、卯午、辰未、**巳申** → **身宫在申**。
3. **定五行局**：生年干辛 → 丙辛之岁起庚寅 → 寅宫庚寅、卯宫辛卯 → 命宫在戌，自卯辛卯顺行：卯辛、辰壬、巳癸、午甲、未乙、申丙、酉丁、**戌戊** → 命宫干支**戊戌**。查纳音歌「戊戌己亥平地木」→ **木三局**。
4. **定紫微**：木三局，查木局口诀及附表定位（如生于初一日则「初一起龙」到辰宫起紫微，逐日推）。
5. **补齐十二宫**：自命宫戌逆布——酉兄弟、申夫妻（身宫亦在此）、未子女、午财帛、巳疾厄、辰迁移、卯奴仆、寅官禄、丑田宅、子福德、亥父母。
6. **安命主身主**：命宫地支戌 → **命主禄存**；生年支丑 → **身主天相**。

**要点**：命宫、五行局、紫微三者环环相扣——命宫的**地支**由生日时决定，命宫的**天干**由年干决定，二者合成的干支纳音再决定从哪一局起紫微。任何一步出错都会全盘偏移。

## 反模式
- **十二宫顺布**：口诀明写「男女俱从逆转切忌莫顺去」。顺布是最常见的排盘错误。
- **混淆命宫与身宫的旋转方向**：命宫**逆**数生时，身宫**顺**数生时，二者同起点反方向。
- **闰月不作下一月**：原书明确「凡有闰月具要依此为例」。
- **用现代万年历直接取命宫地支干支而跳过纳音**：命宫天干必须由「年干起寅」推出，不可直接用当年干支套。
- **忽略「落闲」**：星曜即便庙旺，落入闲宫也须按失位处理。

## 关键要点
1. 排盘四步：定月宫 → 定命身宫 → 由年干+纳音定五行局 → 由局数与生日定紫微。
2. 十二宫逆布且次序固定，命宫是唯一基准。
3. 紫微—天府以寅申为轴镜像分布，「紫府同宫」只在寅申二宫出现。
4. 男女强宫不同：男主财官福迁田，女主夫妻子财田福。
5. 命主由命宫地支定（先天之根），身主由生年支定（后天之用）。
6. 星曜力量 = 本星属性 × 宫支五行生克 × 同宫星互制。
