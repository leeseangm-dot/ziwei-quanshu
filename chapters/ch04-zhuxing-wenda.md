# 第四章：诸星问答论（上）—— 十四主星

## 核心要旨
《诸星问答论》是全书最有系统的一段：每颗主星一问一答，固定回答「这颗星主什么、在各宫如何、庙陷差异、男女命差异」。本章是十四主星的完整属性与判断要点。

## 紫微（属土，中天星，南北斗化帝座，官禄主）

### 星性
面紫色或白青，腰背肥满，为人忠厚老成，谦恭耿直。**其威制七杀，降火铃。**

### 关键判断
- **有相为有用，无相为孤君**：无辅弼同行则虽美玉不足。
- **与府相左右昌曲三合嘉会** → 食禄千钟，巨富大贵。
- **与禄存同** → 奇特。
- **不入庙无左右** → 孤君，亦清闲僧道。
- **与破军同** → 为胥吏。
- **与羊陀火铃冲合** → 吉多亦发财，常庶人吉。
- **三台**：紫微守命是中台，前一位上台，后一位下台。须看三台庙旺否。
- **帝降七杀为权**：有吉同位则帝相有气。
- **帝会文昌拱照 + 美限扶** → 必文选之职。
- **财帛田宅有左右守卫 + 太阴武曲同度** → 财赋之官。
- **与囚（廉贞）同居，无左右相佐** → 定为胥吏。
- **落疾厄、兄弟、奴仆、相貌四陷宫** → 劳碌作事无成。

### 希夷先生曰
紫微为帝座，在诸宫能降福消灾，解诸星之恶虚。**能制火铃为善，能降七杀为权。** 若得府相左右昌曲吉集，无有不贵。纵有四杀冲破亦作中局。
- 遇破军在辰戌丑未 → 为臣不忠、为子不孝。
- 女命逢之作贵妇断；加杀冲破亦作平常，不为下贱。

### 玉蟾先生曰
以左辅右弼为相，天相昌曲为从，魁钺为传令，日月为分司，禄马为掌爵之司，天府为帑藏之主。
**如遇四杀（羊陀火铃）、劫空机梁冲破，定是僧道。**

### 紫微歌（原文）
> 紫微原属土，官禄宫主星，有相为有用，无相为孤君，诸宫皆降福，逢凶福自申，
> 文昌发科甲，文曲受皇恩，僧道有师号，快乐度春秋，众星皆拱照，为吏协公平，
> 女人会帝座，遇吉事贵人，若与桃花会，飘荡落风尘，擎羊火铃聚，鼠窃狗偷群，
> 三方有吉拱，方作贵人评，若还无辅弼，诸恶共饮凌，帝为无道主，考究要知因，
> 二限若遇帝，喜气自然新。

## 天机（属木，南斗第三益算善星，兄弟主）

### 星性
后化气曰善。入庙身长肥胖，性急心慈，机谋多变。**无恶虐不仁之心，有灵机应变之志。**
女命遇之为福，逢吉为吉，遇凶为凶。或守于身，更逢天梁，必有高艺随身。

### 关键判断
- 与天梁会合 → 善谈兵。
- 乙丙丁生人遇之入庙化吉，得左右昌曲魁钺太阴凑合，坐于巳酉丑亥卯未宫 → 权禄不小，文武皆大贵极品。
- **加巨门羊陀火铃忌，巳酉丑亥为下局** → 孤穷，纵有财官贵显亦不耐久，只宜经商巧艺。
- 希夷先生：**天机益寿之星**，若守身命主人异常。居陷地四杀冲破是为下局，当为僧道之清闲。
- 凡入二限逢之，兴家创业更改。

### 天机歌（原文）
> 天机兄弟主，南斗正曜星，作事有操略，禀性最高明……
> 会吉主享福，入格居翰林，巨门同一位，武职压边庭，亦要权逢杀，方可立功名
> 天梁星同位，定作道与僧，女人若逢此，性巧必淫奔，天同与昌曲，聚拱主华荣
> 辰戌子午地，入庙有功名，若在寅卯位，四杀并破军，羊陀及火铃，若与诸杀会，
> 灾患有虚惊，武暗廉破会，两目少光明，二限临此宿，事必有变更。

**要点**：天机逢天梁 → 僧道之命；天机在寅卯逢四杀破军 → 灾患有虚惊；会武曲巨门廉贞破军 → 目疾。

## 太阳（属火，日之精，南北斗化贵，官禄主）

### 星性
乃造化之表仪。男作父星，女为夫主。入庙形貌堂堂，雄壮面方圆满。夜生陷，日生庙旺。

### 关键判断
- **最宜在官禄宫**。
- 命逢诸吉守照，更得太阴同照 → 富贵全美。
- 身逢吉聚 → 贵人门下客；否则公卿走卒。
- 六庚生人命坐卯宫 → 第一庙所，六壬次之。
- 命在亥，申生人下局 → 否则夭寿贫穷，虽发不耐久。
- 庙旺终身富贵；**陷地虽化权禄也凶**，官禄亦不显，先勤终懒，成败不一，出外离祖可吉。
- 与羊陀冲破又陷下局 → 横发横破不耐久。
- 加凶杀带疾，化忌目疾。
- 女命入庙旺夫益子；陷地又见羊陀火铃忌劫 → 贫贱残疾。

### 玉蟾先生曰（太阳十二宫位的宫位意义）
**这是本书少见的「太阳依宫位定性质」的系统说明：**
- 在寅卯为**初升**
- 在辰巳为**升殿**
- 在午为**日丽中天** → 主大富贵
- 在未申为**偏垣** → 作事先勤后惰
- 在酉为**西没** → 贵而不显，秀而不实
- 在戌亥子为**失辉** → 更逢巨暗一生劳碌贫忙，主眼目有伤，与人寡合招非

**女命逢之夫星不美**。若与禄存同宫 → 虽主财帛亦辛苦不闲。若与左右同宫则为贵论。又嫌火铃刑忌，未免先克其父。

### 太阳在十二宫的专论（原文摘要）
- **夫妻宫**：亦为强宫，男为诸吉聚可因妻得贵；陷地加杀伤妻不吉。
- **男女宫**：得八座加吉星在庙旺 → 主生贵子。
- **财帛宫**：于旺地会吉相助 → 不怕巨门缠，富贵绵远。旺相无空劫 → 一生主富。
- **田宅宫**：得祖父荫泽。
- **迁移宫**：其福与身命不同，难招祖业，移根换叶，出祖为家。限步逢之决要动移。女命逢之不吉；若福德宫有相佐，招贤明之夫。
- **父母宫**：男子单作父星，有辉则吉，无辉克父。

### 太阳歌（原文）
> 太阳原属火，正主官禄星，若居身命位，禀性最聪明，慈爱量宽大，福寿享遐龄，
> 若与太阴会，骤发贵无伦，有辉照身命，平步入金门，巨门不相犯，升殿承君恩，
> 偏垣逢暗度，贫贱不可言，男人必克父，女命夫不全，火铃逢若定，羊陀眼目昏，
> 二限若值此，必定卖田园。

## 武曲（北斗第六星，属金，财帛宫主）

### 星性
性刚果决，有喜有怒，可福可灾。与天府同宫有寿。在天司寿，在数司财。

### 关键判断
- **怕受制入陷，喜禄存而同政。**
- 与太阴互权，天府天相为佐贰之星。
- **恶杀耗囚会于震宫（卯）** → 必见木压雷震。
- **破军贪狼会于坎宫（子）** → 必主投河溺水。
- 会禄马 → 发财远郡。
- **贪狼会则少年不利**：「武曲守命福非轻，贪狼不发少年郎」。
- 庙乐桃花同宫 → 利己损人。
- **七杀火星同宫 → 因财被劫。**
- 遇羊陀则孤克，遇破军难显贵。
- 若与破军同位更临二限之中 → 定主是非之挠。
- 甲己生人福厚，出将入相。更得贪火冲破 → 定为贵格。
- 喜西北生人；东南生人平常，不守祖业。
- 四杀冲破 → 孤贫不一，破相延年。
- 女命吉多为贵妇；加杀冲破孤克。

## 天同（属水，南方第四星，福德宫主宰）

### 星性
化福。**最喜遇吉曜，助福添祥。** 为人廉洁，貌禀清奇。有机枢无亢激。
**不怕七杀相侵，不怕诸杀同缠。** 限若逢之一生得地，十二宫中皆曰福，无破定为祥。

### 关键判断
- 身命值之 → 为人谦逊，禀性温和，必慈鲠直，文墨精通。
- 遇左右昌梁 → 贵显。
- 喜壬乙丙生人，巳亥得地。
- **不宜六庚生人居酉地** → 终身不守。
- **会四杀居巳亥为陷** → 残疾孤克。
- 女人逢杀冲破 → 刑夫克子。
- 梁月冲破 → 合作偏房，僧道宜之。

## 廉贞（属火，北斗第五星）

### 星性
在斗司品秩，在数司权令。**不临庙旺，更犯官符，故曰化囚为杀。**
主人心狠性狂，不习礼义。

### 关键判断
- **逢帝座** → 执威权
- **遇禄存** → 主富贵
- **遇文昌** → 好礼乐
- **遇杀曜** → 显武职
- **在官禄** → 有威权
- **在身命** → 为次桃花
- 若居旺宫 → 赌博迷花而致讼
- 限逢巨门于陷地 → 是非起于官司
- 逢财星耗合 → 祖业必破
- 遇刑忌 → 脓血不免
- 遇白虎 → 刑杖难逃
- 遇武曲于受制之乡 → 恐木压蛇伤
- 同火曜于陷空之地 → 主投河自缢
- 破军与日月以济行 → 目疾而不免
- **只宜官禄身命之位**，遇吉福映，逢凶则不慈。

### 廉贞歌
> 廉贪巳亥宫，遇吉福盈丰，应过三旬后，须防不善终。

## 天府（属土，南斗主令第一星，财帛主宰）

### 星性
在斗司福权之宿，会吉皆为富贵之基。**能制羊陀为从，能化火铃为福。**
主人相貌清奇，禀性温良端雅。

### 关键判断
- **天府为禄库，命逢终是富。**
- 与昌曲会 → 必登首选
- 逢禄存武曲 → 必有巨万之富
- **不喜四杀冲破** → 虽无官贵，亦主财田富足
- **以田宅财帛为庙乐，以奴仆相貌为陷弱，以兄弟为平常**
- 命逢之得相佐 → 夫妻子女不缺
- **若值空亡是为孤立**
- **此星不论诸宫皆吉**；女命得之清正机巧，旺夫益子，虽见冲破亦以善论。

### 天府歌
> 天府为禄库，入命终是富，万顷置田庄，家资无论数，女命坐香闺，男人食天禄，
> 此是福吉星，四外无不足。

## 太阴（水之精，田宅主，化富，与日为配）

### 星性
其为人也聪明俊秀，其禀性也端雅纯祥。
**上弦为要之机，下弦减威之论。** 男为妻宿，又作母星。

### 关键判断
- 若相生坐于太阳，日在卯，月在酉 → 俱为旺地，为富贵之基。
- 命坐银辉之宫，诸吉咸集 → 为享福之论。
- 若居陷地 → 则落弱之名。
- **仍以不逢巨门为佳。**
- 身若居之 → 有随娘继拜，或离祖过房。
- 身命若见恶杀交冲 → 必作伤残之论；除非僧道反获祯祥。
- **与文曲同居身命 → 定是九流术士。**

### 希夷先生曰（太阴庙陷）
- **以卯辰巳午未为陷地，以酉戌亥子丑为得垣。**
- 酉为西山之门，为东潜之所。
- 嫌巨曜以来缠，怕羊陀以同度，廉囚相犯，七杀相冲 → 恐非得意之垣，定作伤残之论。
- **在疾厄遇陀暗为目疾**，遇火铃为灾，值贪杀损目。
- **在父母**，如陷地失辉，遇流年白虎太岁 → 主母有灾。
- 若逢白虎、丧门、吊客 → 妻亦慎之。

## 贪狼（北斗解厄之神第一星，属水，化气为桃花）

### 星性
化气为桃花，为标准，乃主祸福之神。**受善恶定奸诈瞒人。** 又好高吟浮荡，作巧成拙。
入庙乐之宫，可为祥可为祸。

### 关键判断
- 会破军 → 迷花恋酒而丧命
- 同禄存 → 可吉
- 遇耗 → 因以虚花
- 遇廉贞 → 也不洁
- 见七杀 → 或配以遭刑
- **遇羊陀主痔疾**，逢刑忌有斑痕
- **与七杀同守身命** → 男有穿窬之体，女有偷香之态
- **诸吉压不能为福，众凶聚愈藏其奸**——这是贪狼最关键的特性
- 「七杀守身终是夭，**贪狼入庙必为娼**」
- 若身命与破军同居，更居三合之乡生旺之地 → 男好饮而赌博游荡，女无媒而自嫁
- **喜见空亡，返主端正**——空亡反能制贪狼之淫
- 与武曲同度 → 为人谄佞奸贪，每存肥己之心
- 与贞（廉贞）同 → 公庭必定遭刑
- 四杀同 → 定为屠宰
- 羊陀交并 → 必作风流之鬼
- 昌曲同度 → 必多虚而少实
- **惟会火铃能富贵**——火贪格／铃贪格
- 在田宅 → 破荡祖业，先富后贫
- **总而言之，男女非得地之星，不见尤妙。**

### 希夷先生曰
贪狼为北斗解厄之神，陟明之星，其气属木，体属水，故化气为桃花。主人矮小，性刚猛威，机深谋远，随波逐浪，爱憎难定。
- **居庙旺遇火星武职权贵**，戊己生人合局
- 遇天相延寿，会廉武巧艺，得禄存僧道宜之
- 破杀相冲 → 飘蓬度日
- 女人刑克不洁，遇太阴则主淫佚

## 巨门（属水金，北斗第二星，化气为暗）

### 星性
为阴精之星，化气为暗。**在数则掌执是非，主于暗昧，疑是多非。**
其性则面是背非，六亲寡合，交人初善终恶。

### 十二宫断语（本书最完整的「一星通十二宫」范例）
| 宫位 | 巨门之应 |
|---|---|
| 身命 | 一生招口舌之非 |
| 兄弟 | 骨肉参商 |
| 夫妻 | 主于隔角，生离死别，纵有对不免污名失节 |
| 子息 | 损后方招，虽有而无 |
| 财帛 | 有争竞之意 |
| 疾厄 | 遇刑忌眼目之灾，杀临主残疾 |
| 迁移 | 招是非 |
| 奴仆 | 多怨逆 |
| 官禄 | 主招刑杖 |
| 田宅 | 破荡祖业 |
| 福德 | 其祸稍轻 |
| 父母 | 遭弃掷 |

### 关键判断
- **十二宫中若无庙乐照临，到处为灾，奔波劳碌。**
- 至亥寅巳申 → 虽富贵亦不耐久。
- **会太阳则吉凶相半**，逢七杀则主杀伤。
- 贪耗同行 → 因好徒配。
- **遇帝座则制其强，逢禄存则解其厄**——紫微、禄存是巨门的两大解药。
- 值羊陀 → 男盗女娼。
- 对宫遇火铃、白虎，无帝压制 → 决配千里。
- 除为僧道九流，方免劳神偃蹇。

## 天相（属水，南斗第五星，化气曰印，官禄文星）

### 星性
为司爵之宿，为福善。**言语诚实，事不虚伪。** 见人难有恻隐之心，见人恶抱不平之气。

### 关键判断
- 官禄得之则显荣，帝座合之则争权。
- **佐日月之光，兼化廉贞之恶**——天相能化解廉贞的恶性。
- 十二宫中皆为祥福，**不随恶而变志，不因杀而改移**。
- 此星若临生旺之乡，虽不逢帝座，若得左右则职掌威权。
- 或居闲弱之地，也作吉利。
- 陷地贪廉武破羊陀杀凑 → 巧艺安身。
- 火铃冲破 → 残疾。
- 女人主聪明端庄，志过丈夫。

### 天相歌
> 天相原属水，化印主官禄，身命二宫逢，定主多财福，形体又肥满，语言不轻渎，
> 出仕主飞腾，居家主财谷，二限若逢之，百事看充足。

## 天梁（属土，南斗第二星，化气为荫为福寿，父母主）

### 星性
司寿化气为荫为福寿，乃父母之主，命化暴戾为祥和。
性情磊落，相貌厚重温谦，循直无私。临事果决，荫于身福及子孙。

### 关键判断
- 遇昌曲于财宫，逢太阳于福德三合 → 乃万全声名。
- **命或对宫有天梁主有寿，乃极吉之星。**
- 若逢耗曜，更逢天机及杀 → 宜僧道。
- 逢贪巨同度 → 而乱礼乱家。
- 居奴仆、疾厄、相貌 → 作丰余之论。
- **见廉贞刑忌，必无灾厄克激之虞；遇火铃刑暗，亦无征战之挠。**
- **太岁冲而为福，白虎临而无殃。**
- 奏书会则有意外之荣，青龙动则有文书之喜。

### 天梁歌
> 天梁原属土，南斗最吉星，化荫名延寿，父母宫主星……
> 巨门若相会，劳碌历艰辛，若逢天机照，僧道享山林，二星在辰戌，福寿不须论。

## 七杀（南斗第六星，属火金，斗中上将）

### 星性
乃斗中之上将，实成败之孤辰。在斗司斗柄，主于风宪。
**主于数则宜僧道，主于身定历艰辛。**

### 关键判断
- 在命宫若限不扶 → 夭折。
- 在官禄得地 → 化祸为祥。
- 在子息 → 子息孤单。
- 居夫妇 → 鸳衾半冷。
- 会刑囚于田宅、父母 → 刑伤父母，产业难留。
- 逢刑忌杀于迁移、疾厄 → 终身残疾。
- 与囚（廉贞）于身命 → 折肱伤股，又主痨伤。
- 会囚耗于迁移 → 死于道路。
- **遇紫微则化权降福，遇火铃则长其杀威。**
- 「七杀居陷地，沉吟福不生。」
- 遇帝禄而可解，遭流杀而逢凶。
- 左右昌曲入庙拱照 → 掌生杀之权，富贵出众。
- 若四杀忌星冲破 → 巧艺平常之人，陷地残疾。
- 女命旺地 → 财权服众，志过丈夫。

### 七杀歌

### 关键判断

## 反模式
- **忽略「有相／无相」**：紫微、天府这类帝星级的主星，无辅弼则格局崩塌。「有相为有用，无相为孤君」是硬规则。
- **贪狼见吉即判吉**：「诸吉压不能为福，众凶聚愈藏其奸」——贪狼是全书唯一明说「诸吉不能救」的星。
- **巨门不论制化**：巨门遇紫微、禄存是两大解药，不解此二则断语会过重。
- **太阳太阴不看宫位**：太阳在午（日丽中天）与在戌亥子（失辉）是两个极端，玉蟾先生给的宫位系统必须先套。
- **七杀破军单论凶**：七杀遇紫微化权降福，破军遇天梁制恶、天禄解狂，皆有生路。

## 推演实例：判断紫微在午守命的格局层次
1. **定庙陷**：紫微在午为入庙。太阳同在午则成「日丽中天」。
2. **有无辅弼**：若左辅右弼同宫或夹 → 「一呼百诺居上品」，上格。若无 → 孤君，格局大降。
3. **有无三合吉会**：府相、昌曲、日月、禄马三合嘉会 → 食禄千钟，巨富大贵。
4. **检查四杀**：擎羊火铃会 → 「擎羊火铃聚，鼠窃狗偷群」；但「吉多亦发财」——杀星多寡是关键。
5. **加破军在辰戌丑未** → 「为臣不忠，为子不孝」，格局转劣。
6. **结论**：
   - 庙 + 辅弼齐 + 三合吉 → 上上之命
   - 庙 + 无辅弼 → 中局，孤君
   - 庙 + 破军 + 四杀 → 下局，胥吏
7. **叠限验证**：二限遇帝 → 「喜气自然新」；但若限逢杀破狼三方 → 「紫微入限本为祥，只恐三方杀破狼」。

## 关键要点
1. 十四主星各有「化气」（善、贵、财、福、印、荫、耗、暗、桃花杀、杀囚），化气决定星的核心职能。
2. **制化关系是关键**：紫微制火铃降七杀，天相化廉贞之恶，天梁制破军之恶，天禄解破军之狂，紫微禄存解巨门之厄，天同不畏诸杀。
3. 贪狼是唯一「诸吉不能制」的凶星（不喜空亡反主端正），最特殊。
4. 紫微、天府、太阳、太阴这四颗「帝后日月」级星曜，对宫位和辅弼的依赖远大于其他星。
5. 每颗星的男女命断法不同——女命不宜贪狼、七杀单居福德。
