# 第六章：斗数骨髓赋 —— 判词总汇

## 核心要旨
骨髓赋是全书判词密度最高的一篇。它不讲单星性质，而是把**星曜组合、宫位配合、限运叠加**的断语压缩成对句，可直接查用。使用方法是「条件匹配」：找到与手中盘面相符的判词，逐条验证。

## 判盘次序（赋首明文）
> 太极星缠，乃群宿众星之主，天门运限，即扶身助命之源，在天则运用无常，在人则命有格局。

**次序**：
1. **先明格局，次看众星。**
2. **祸福不可一途而惟，吉凶不可一例而断。**
3. **要知一世之荣枯，定看五行之宫位。立命可知贵贱，安身便晓根基。**
4. **第一先看福德，再三细考迁移，分对宫之体用，定三合之源流。**

这是全书唯一明说「**第一先看福德**」的地方——福德宫优先于财官。

## 星性四句总诀（赋中最实用的一组）
> **论命必推星善恶，巨破擎羊性必刚。**
> **府相同梁性必好，火劫空贪性不常。**
> **昌曲禄机清秀巧，阴阳左右最慈祥。**

这是把星曜按「性格倾向」分成四组：
- **性刚**：巨门、破军、擎羊
- **性善**：天府、天相、天同、天梁
- **性无常**：火星、地劫、地空、贪狼
- **清秀巧**：文昌、文曲、禄存、天机
- **慈祥**：太阳、太阴、左辅、右弼

> 心好命微亦主寿，心毒命固亦夭亡。

## 反模式
- **不先看福德**：赋明言「第一先看福德，再三细考迁移」。跳过福德直接看财官是次序错误。
- **夹宫只看一颗**：夹宫须两星同夹才算数，且吉凶属性分明（夹禄吉、夹羊凶）。
- **以「心好命微亦主寿」当安慰**：这句与「阴骘延年增百福」呼应，是本书明确的**德行影响命数**主张，不是修辞。
- **判词只看主句不看限定**：如「紫微居午无杀凑，位至三公」——「无杀凑」是必要条件，漏读即误断。
- **忽略「命好身好限好」的三重结构**：命、身、限任一环节崩坏都会拖垮全局。

## 推演实例：用骨髓赋交叉验证一个盘
情境：某人紫微在午守命，天府在戌，左辅右弼同宫拱照，文昌在寅，擎羊在酉。

1. **先看福德**（赋中次序）：假设福德宫为天梁 —「天梁原属土，南斗最吉星，化荫名延寿」，福德佳。
2. **匹配格局判词**：
   - 「紫微居午无杀凑，位至三公」→ 但需确认「无杀凑」。擎羊在酉，酉不在午的三合（寅午戌），故不算凑，条件成立。
   - 「紫微辅弼同宫一呼百诺居上品」→ 辅弼同宫，成立。
   - 「左辅文昌会吉星尊居八座」→ 辅弼与文昌会吉，成立。
   - 「天府临戌有星扶腰金衣紫」→ 天府在戌得星扶，成立。
3. **检查夹宫**：若紫微在午，前一宫巳与后一宫未的两星夹午 → 须看巳未为何星。若夹禄存化禄 → 夹禄，吉；若夹空劫 → 夹空，凶。
4. **检查反背**：「日月最嫌反背」——若太阳在酉、太阴在卯，则反背失辉，需在盘中核验。
5. **结论层次**：紫府朝垣 + 辅弼昌 + 无杀凑 → 上格，「公侯器」。
6. **叠加限运**：限至天空 → 「项羽英雄限至天空而丧国」；限至劫地 → 「石崇豪富限行劫地以亡家」。以此提示风险年份。

**要点**：骨髓赋的正确用法是**先定盘面事实，再去找匹配的判词**——而不是先背判词再去套盘。

## 关键要点
1. 判盘次序：**格局 → 众星 → 五行宫位 → 立命安身 → 福德 → 迁移 → 对宫体用 → 三合源流**。
2. 福德宫优先级高于财官，这是本书的明确主张。
3. 夹宫是关键技法：夹禄权科贵日月昌曲为吉，夹空劫羊陀为凶。
4. 「论命必推星善恶」四句总诀把星曜按性格分组，是最快的星性索引。
5. 德行可改命数：「阴骘延年增百福」「心好命微亦主寿」——本书承认阴德对命数的修正作用。
6. 大量格局名（紫府朝垣、日月并明、月朗天门、石中隐玉、极居卯酉等）在此定型，是后世格局说的源头。
