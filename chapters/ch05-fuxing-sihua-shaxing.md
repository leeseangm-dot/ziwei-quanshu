# 第五章：诸星问答论（下）—— 辅星、四化与煞星

## 核心要旨
本篇覆盖非主星系：**辅佐星（昌曲辅弼魁钺禄存天马）、四化星（禄权科忌）、煞星（羊陀火铃空劫伤使刑姚哭虚）**。这些星决定主星能否发挥——主星定格局上限，辅煞定成败。

---

## 一、辅佐星

### 文昌（主科甲）
守身命主人幽闲儒雅，清秀魁梧，**博文广记，机变异常**，一举成名，披绯衣紫，福寿双全。
- **纵四杀冲破不为下贱。**
- 女人加吉得地 → 衣禄充足；四杀冲破 → 偏房下贱，僧道宜之。
- 加权禄厚重有师号。

**文昌歌**：
> 文昌主科甲，辰巳是旺地，利午嫌卯酉，火生人不利，眉目定分明，相貌极俊丽，
> 喜于金生人，富贵双全美，先难而后易，中晚有声名，太阳荫福集，传胪第一名。

**要点**：辰巳旺地，卯酉不利，火年生人不利。午宫有利。金年生人最喜。

### 文曲（属水，北斗第四星，主科甲文车之宿）
- 与文昌同协，吉数最为祥。
- 桃花浪暖，入仕无疑；于官禄面君颜而执政。
- **单居身命，吏逢凶曜** → 亦作无名舌辩之徒。
- **与廉贞共处** → 必作公吏官。
- **身与太阴同行** → 定系九流术士。
- **怕逢破军**恐临水以生灾；**嫌遇贪狼**莅政事而颠倒。
- 逢七杀刑忌囚及诸恶曜 → 诈伪莫逃。
- 逢巨门共其度 → 和而丧志。
- 女命不宜于逢，水性杨花。
- **忌入土宫**，限临蹭蹬。
- 若禄存、化禄来缠 → 不可以为凶论。

**希夷先生曰**：文曲守身命，居**巳酉丑宫居侯伯**。武贪三合同垣 → 将相之格。若陷宫午戌之地，巨门羊陀冲破 → 丧命夭折，水大惊险。若**亥卯未旺地**，与天梁天相会主聪明博学；杀冲破只宜僧道。

### 流年昌曲（论科考）
命逢流年昌曲 → 为科名科甲。大小二限逢之，三合拱照太阳，又照流年禄；小限太岁逢魁钺、左右、台座、日月、科权禄马三方拱照 → **决然高中无疑**。
- 但须此数星俱全方为大吉，以流年科甲为主。
- 二星在巳酉得地 → 不富即贵，只是不能耐久。

**昌曲歌**：
> 南北昌曲星，数中推第一，身命最为佳，诸吉恐非吉，得居人命上，桃花浪三汲，
> 入仕更无虚，从容要辅弼，只恐恶杀临，火铃羊陀激，若还逢陷地，苗而不秀实，
> 不是公吏辈，九流工数术，无破宰职权，女人多淫佚，乐居亥子宫，空亡官无益。

**要点**：**「诸吉恐非吉」**——昌曲虽为吉星，但单见且无辅弼时反而非吉。乐居亥子，但落空亡则官无益。

### 左辅
帝极主宰之星，守身命诸宫降福。主人形貌敦厚慷慨风流。
- 紫府禄权若得三合冲照 → 主文武大贵。
- **火忌冲破，虽富贵不久。**
- 僧道清闲；旺地封赠。

### 右弼
帝极主宰之星，守身命文墨精通。
- 紫府吉星同垣 → 财官双美，文武双全。
- **羊陀火忌冲破 → 下局断之。**
- 女人贤良有志，**纵四杀冲破，不为下贱**。

**辅弼歌**：
> 左辅原属土，右弼水为根，失君为无用，三合宜见君，若在紫微位，爵禄不须论，
> 若在夫妻位，主人定二婚，若与廉贞并，恶贱遭钳髡，辅弼为上相，辅佐紫微星，
> 喜居日月侧，文人遇禹门，倘居闲位上，无爵更无名，妻宫遇此宿，决定两妻成，
> 若与刑囚处，遭伤作盗贼。

**要点**：**「失君为无用」**——辅弼离开紫微（君）则无用。夫妻宫遇辅弼 → 决定二婚，这是重要断语。

### 天魁天钺（斗中司科之星）
- 入命坐贵向贵，或得左右吉聚 → 无不富贵。
- 二星为**上界和合之神**，若魁临命、钺守身，更迭相守。
- 遇紫微府、日月、昌曲、左右、权禄相凑 → 少年必聚美妻。
- **若遇大难，必得贵人成就扶助。**
- 限步巡逢 → 必主女子添喜，生男则俊雅，入学功名有成。
- 生女则容貌端庄，出众超群。
- **若四十以后逢墓库，不依此断。**
- 有凶不以为灾；居官者贤而威武。
- 女人吉多 → 宰辅之妻，命妇之论；若加恶杀亦为富贵，但不免私情淫佚。

**魁钺歌**：
> 天乙贵人众所钦，命逢金带福弥深，飞腾名誉人争慕，博雅皆通古与今，
> 魁钺二星限中强，人人遇此广钱粮，官吏逢之发财福，当年必定见君王。

### 禄存（北斗第三星，真人之宿）
- 主人贵爵，掌人寿基。
- 帝相扶之施权，日月得之增辉。
- 天府武曲为厥职，天梁天同共其祥。
- **十二宫中惟身命、田宅、财帛为要，主富。**
- 居迁移则佳；与帝星守官禄宜子孙爵秩。
- **若独守命而无吉化，乃看财奴耳。**
- 逢吉逞其权，遇恶败其迹。
- **最嫌落于陷空不能为福**；更凑火铃空劫 → 巧艺安身。
- 守身命主人慈厚信直，通文济楚。
- 女人清淑机巧能干能为，有君子之志。
- **大抵此星诸宫降福消灾。**

**禄存歌**：
> 斗北禄存星，数中为上局，守值身命内，不贵多金玉，此为迪吉星，亦可登仕路……
> 夹禄拱贵并化禄，金里重逢金满屋，不惟方丈比诸侯，一食万锺犹未足，
> 禄存对向守迁移，三合逢之利禄宜，得逢遐迩人钦敬，的然白手起家基。

### 天马（驿马）—— 七种马的判法
这是本书最实用的「一星多变」范例：

| 组合 | 名称 | 应验 |
|---|---|---|
| 与禄存同宫 | **禄马交驰**／折鞭马 | 吉，主财禄 |
| 与紫府同宫 | **扶轝马** | 吉 |
| 与刑杀同宫 | **负尸马** | 凶 |
| 与火星同宫 | **战马** | — |
| 与日月同宫 | **雌雄马** | — |
| 逢空亡 | **死马／亡马** | 凶 |
| 居绝死 | **死马** | 凶 |
| 遇陀罗 | **折足马** | 凶 |

**以上犯此数者，俱主灾病，流年值之依此断。**

## 二、四化星

| 四化 | 性质 | 守身命之应 |
|---|---|---|
| **化禄** | 福德之神 | 科权相逢必作大臣之职；小限逢之主进财入仕；大限十年吉庆；恶曜并羊陀火忌冲照亦不为害 |
| **化权** | 掌判生杀之神 | 科禄相逢出将入相；科权相逢必文章冠世；如逢羊陀耗使劫空 → 听谗贻累，官灾贬谪 |
| **化科** | 上界应试，主掌文墨之星 | 权禄相逢宰臣之贵；逢恶曜亦为文章秀士，可作群英师范 |
| **化忌** | 多管之神 | 一生不顺；小限逢之一年不足；大限十年悔吝；二限太岁交临断然蹭蹬 |

**化忌的关键细节**：
- 文人不耐久，武人纵有官灾口舌不妨。虽商贾技艺人，皆不宜利。
- **如会紫府、昌曲、左右、科权禄，与忌同宫又兼四杀共处 → 即发财亦不佳，功名亦不成就。**
- 如单逢四杀、耗使、劫空 → 主奔波带疾。
- 僧道流移还俗。**处事只求七分。**

**要点**：化忌是全书唯一明说「即使有紫府昌曲左右科权禄也救不回来」的星（前提是同时兼四杀）。这是判断盘面凶险程度的重要门槛。

## 三、煞星

### 擎羊（北斗之助星）
守身命**性粗行暴，孤单，视亲为疏，翻恩为怨**。
- 入庙性刚果决，机谋好勇，主权贵。
- 北方生人为福，四墓生人不忌。
- **居卯酉作祸兴殃，刑克极甚。**
- 六甲六庚生人，必有凶祸。纵富贵不久亦不善终。
- 加火忌劫空冲破 → 残疾离祖刑克六亲。
- 女人入庙加吉上局；杀耗冲破多主刑克下局。

### 陀罗（北斗之助星）
守身命**心行不正，暗泪长流，性刚威猛，作事进退**。横成横破，飘荡不定。
- 与贪狼同度 → 因酒色以成痨。
- 与火铃同处 → 疥疫不死。
- 居疾厄 → 暗疾缠绵。
- 辰戌丑未生人为福；在庙财官论。
- 文人不耐久，武人横发高迁。
- 若陷地加杀刑克招凶，二姓延生；女人刑克下贱。

### 羊陀二星总论（玉蟾先生曰）
擎羊陀罗二星属火金，乃北斗浮星。**羊化气曰刑，陀化气曰忌。**
- **怕临兄弟、田宅、父母三宫。**
- 忌三合临身命。
- 合昌曲、左右 → 有暗痣、眼痣。
- 见日月 → 女克夫，而夫克妇。
- 忌同日月 → 则伤亲损目
- 刑并桃花 → 则风流惹祸
- 忌贪狼合 → 因花酒以忘身
- 刑与暗同行 → 招暗疾而坏目
- 忌与杀暗同度 → 招凌辱而生暗疾
- 与火铃为凶伴 → 只宜僧道
- 权刑合杀 → 疾病官厄不免
- 贪耗流年 → 面上刺痕

**羊陀歌**：
> 刑与暗同行，暗疾刑六亲，火铃遇凶伴，只宜道与僧，权刑囚合杀，疾病灾厄侵，
> 贪耗流年聚，面上刺痕新，限运若逢此，横祸血刃生。
> 羊陀夭寿杀，人遇为扫星，君子防恐惧，小人遭凌刑，遇耗决乞求，只宜林泉人，
> 二限倘来犯，不时灾祸侵。

### 火星（南斗浮星）
性刚强出众，唇齿四肢有伤，毛发有异。**诸宫不美，惟贪狼庙旺同度，指日立边功**，为财官格。
- 利东南生人，不利西北生人。
- 喜寅卯巳午生人为祸较轻。
- 更与擎羊同垣 → 则襁褓灾厄，孤克下局，只宜过房由外家寄养，或重拜父母方可。
- 女命心毒内狠外虚狡诈，凌夫克子，不守妇道，多是非，淫欲下贱。
- **寅午戌人宜**；申子辰人陷灾吝困顿；巳酉丑人得地吉；亥卯未人利益，吉多发福。

### 铃星（南斗浮星）
性毒形神破相，胆大出众。
- **宜寅午戌人权贵**；亦利东南生人限行福厚；西北生人限行成败，虽富贵亦不耐久。
- **入庙遇贪狼武曲 → 威镇边夷**；更会紫府左右不贵即富。
- 如居陷地夭折破相延寿，或离祖重拜父母。
- 女命性刚背六亲，伤夫克子；遇吉始能丰足。

### 火铃二星总论
- **火铃二曜居庙地，贪狼紫府宜相会** → 为人性急有威权，镇压乡邦终有贵。
- **火铃在命落闲宫，西北生人作事庸** → 破尽家财终不久，须教带疾免灾凶。
- 女命：火铃之星入命来，贪狼相会得和谐；三方无杀诸般美。火铃二曜最难当，女命逢之必刑伤。

**要点**：火铃是「唯一能成就贪狼」的煞星——火贪格、铃贪格。除此以外诸宫皆不美。

### 地劫（劫杀之神，属火）
性恶作事疏狂，动静增恶，**不行正道，为邪僻之事**。有吉祸轻，三方四正加杀多者夭寿论。
女命只可为偏房妓婢而已。

**地劫入命**：地劫从来生发疾，命中相遇多啾唧，若遇羊火在其中，辛苦持家防内室。
**地劫入限**：劫星二限若相逢，未免当年有祸危，太岁杀临多疾厄。

### 天空（空亡之神）
性恶作事虚空，不行正道，**成败多端不聚财，退祖荣昌**。名曰**断桥**。
- 有吉祸轻；四杀加少者平常论，多者下贱。
- 太岁二限遇逢，有正曜星加吉者平安。
- 经云：**项羽英雄，限到天空而丧国。**
- 女命单守只可为偏房妓婢。

**天空入命**：命坐天空定出家，文昌天相实堪夸，若逢四杀同身命，受荫承恩福可佳。
**地劫天空同入限**：
> 极居卯酉劫空临，为僧为道福兴隆，乐享山林有师号，福寿双全到古龄。
> 劫空二限最乖张，夫子在陈也绝粮，项羽英雄曾丧国，绿珠逢此坠楼亡。

### 天伤（虚耗之神，属水）
守临二限遇太岁，不问得地，**只要众星吉方可获善**。
若无正星又值羊火巨机 → 必主官灾丧服破财，横事相侵。**夫子绝粮限到天伤。**

## 反模式
- **把辅星当吉星一律论吉**：「辅弼失君为无用」「昌曲诸吉恐非吉」「禄存独守乃看财奴」——辅星的效果完全取决于主星与组合。
- **忽略「主星定上限、辅煞定成败」**：紫微无辅弼成孤君，昌曲无辅弼反不吉，皆是此理。
- **四化只记「禄吉忌凶」**：化权逢羊陀耗使劫空反主官灾贬谪；化科逢恶曜仍可为文章秀士——四化需连看同宫星曜。
- **天马只记「吉星」**：天马必须辨七种马（禄马交驰、折足马、负尸马、死马……），不分种类就断必错。
- **火铃一律论凶**：火铃遇贪狼入庙是财官格，是极重要的例外。

## 推演实例：判断一个盘的「助力结构」
情境：命宫紫微在午，三方见左辅、右弼、文昌，同时擎羊在酉、火星在子。

1. **主星定上限**：紫微在午入庙，得辅弼三合拱照 → 依紫微节「紫微辅弼同宫，一呼百诺居上品」，格局为上。
2. **辅星验证**：昌曲入命 → 「博文广记，机变异常」，主文章科甲。辅弼「三合宜见君」→ 有效，非失君。
3. **查煞星位置**：
   - 火星在子：子为紫微落平之地。火星会紫微 → 「擎羊火铃聚，鼠窃狗偷群」。但紫微「能制火铃为善」——关键看有无辅弼制衡。
   - 擎羊在酉：酉与命宫午不成三方（午三合为寅午戌），故擎羊不直接冲命。
4. **制化判断**：紫微本具制火铃之能，且辅弼齐全 → 「吉多亦发财」。煞星为减分项而非致命伤。
5. **叠加四化**：若化忌落命宫 → 依化忌节「若会紫府、昌曲、左右、科权禄，与忌同宫又兼四杀共处 → 即发财亦不佳」。此时需确认是否有四杀同宫。
6. **结论**：上格但带瑕疵（美玉瑕玷）。用禄存、天梁在限运中化解。

**要点**：判断流程为「主星 → 辅星是否有效 → 煞星落点 → 制化 → 四化」。煞星不是一票否决，而是看能否被制。

## 关键要点
1. **主星定格局上限，辅煞定实际成败。** 辅弼须依附紫微（君）才有效。
2. 四化中**化忌最特殊**：即使紫府昌曲左右科权禄齐聚，若兼四杀则一切皆救不回。
3. 天马有七种变体，须依同宫星曜分辨吉凶。
4. 火铃与贪狼入庙是财官格——这是煞星唯一的大用。
5. 空劫是「断桥」，能使成败多端、不聚财；但利僧道修行（极居卯酉劫空临）。
6. 羊陀怕落兄弟、田宅、父母三宫；化忌与巨门同宫主身弱。
